# 돌멩이 시참 접속기

게임을 선택하고 시참 서버와 같은 모드 구성으로 준비하는 Windows 접속기입니다.

[최신 접속기 다운로드](https://github.com/chambada1060-crypto/dolmeongi-launcher/releases/latest/download/DolmeongiLauncher.exe)

처음 한 번 내려받은 뒤 접속기에서 모드와 접속기를 업데이트하세요. 게임 본편은 각자 Steam에 설치해야 합니다.
모집 중인 게임만 실행할 수 있습니다. 종료된 게임은 실행이 차단되며 운영자가 목록에서 숨길 수도 있습니다.

직접 만든 모드는 이 저장소의 Releases에서, Bannerlord Co-op 원본은 제작자의 Steam Workshop에서 받습니다.
게임 버전과 파일이 서버의 승인 기준과 다르면 실행하지 않습니다. 게임 자체 업데이트는 Steam에서 처리하세요.

현재 초기 검증 단계입니다. 배너로드 연결부터 검증하고 있으며 팰월드는 준비 중입니다.
접속기 검사는 모드 원본의 동기화 버그를 해결하거나 서버의 접속 권한을 대체하지 않습니다.
