# 돌멩이 시참 접속기

게임을 선택하고 시참 서버와 같은 모드 구성으로 준비하는 Windows 접속기입니다.

[최신 접속기 다운로드](https://github.com/chambada1060-crypto/dolmeongi-launcher/releases/latest/download/DolmeongiLauncher.exe)

접속기를 열거나 게임을 바꾸면 접속기 새 버전부터 확인하고, 선택한 게임의 모드를 최신 서버 승인 구성으로 자동 업데이트합니다. 게임 본편은 각자 Steam에 설치해야 합니다.
게임 실행에 성공하면 접속기는 자동 종료됩니다. 준비 중이거나 업데이트·파일 검사에 실패하면 실행 버튼은 잠기고 안내가 표시됩니다. 설치 폴더를 바꾸면 다시 자동 확인합니다.
0.1.10부터 첫 실행 시 문서/돌멩이 접속기 폴더에 설치하고 바탕화면에는 바로가기를 만듭니다. 바탕화면·다운로드 폴더에서 실행한 원본은 설치 확인 후 정리하고, 업데이트 백업은 문서 폴더 안에 보관합니다. 기존 게임 경로 설정은 유지하며 오류 로그 ZIP은 계속 바탕화면에 저장합니다. 별도 위치에 보관한 복사본이나 다른 파일은 지우지 않습니다.
0.1.9에서는 게임패드를 든 기본 돌멩이 아이콘을 적용했습니다. 준비 상태는 게임 실행 바로 아래에 표시하고 자동 종료 안내는 제거했습니다. 창 크기와 여백은 유지합니다.
0.1.8에서는 게임 선택에 마우스를 올릴 때 기본 Windows 버튼이 번쩍이며 보이던 문제를 수정했습니다. 버튼 표시를 분리해 테마를 유지합니다.
0.1.7에서는 화면을 더 작게 정리하고 게임 실행 왼쪽의 `수동 업데이트 하기` 하나로 접속기·모드 업데이트와 구성 검사를 통합했습니다. 게임 실행 직전에도 자동으로 준비하며, 중간에 선택 게임이 종료·숨김되면 다른 게임을 대신 실행하지 않습니다. 문제 해결은 왼쪽 하단에 모으고 게임 선택·창 버튼·준비 내역 스크롤을 같은 테마로 맞췄습니다. 기본 검사 74개와 실제 Windows 폼 흐름·배치 검사 38개를 통과했으며 실제 미리보기에서 글자 잘림과 스크롤 드래그를 확인했습니다.
0.1.6부터 남색·차콜·청록 화면으로 개편하고 `오류 로그 저장`을 추가했습니다. 선택한 게임의 최근 로그와 접속기 기록을 바탕화면 ZIP으로 모아 파일 위치를 엽니다. 이 ZIP을 운영자에게 메일이나 디스코드로 직접 전달하세요. 자동 전송은 하지 않습니다. 현재 배너로드·팰월드의 로그 위치를 지원하며 다른 게임은 접속기 기록만 저장합니다. 서버·게임 운영 상태는 기존 설정을 따릅니다.
세이브·설정·메모리 덤프는 제외합니다. 알려진 인증값·사용자 경로·IP·Steam ID 형식은 가리지만 닉네임 등은 남을 수 있습니다. 큰 로그는 시작 부분과 최근 부분만 포함하고 읽지 못한 파일은 진단 요약에 표시합니다.74개 회귀·로그 검사와24개 폼 흐름 검사, 실제 배너로드 로그 ZIP 저장을 확인했습니다.
모집 중인 게임만 실행할 수 있습니다. 종료된 게임은 실행이 차단되며 운영자가 목록에서 숨길 수도 있습니다.

직접 만든 모드는 이 저장소의 Releases에서, Bannerlord Co-op 원본은 제작자의 Steam Workshop에서 받습니다.
게임 버전과 파일이 서버의 승인 기준과 다르면 실행하지 않습니다. 게임 자체 업데이트는 Steam에서 처리하세요.

배너로드 시작 화면과 모드 로드를 확인했으며 팰월드는 준비 중입니다. 캠페인 접속·다른 참가자 PC는 추가 확인이 필요합니다.
접속기 새 버전이 있으면 자동 교체 후 다시 열립니다. 관리 창이 열려 있으면 닫고 다시 확인하세요. 실패하면 기존 파일 보존 또는 시작 실패 시 복원을 시도하며 안내와 기록을 남깁니다.
자동 업데이트가 계속 실패하면 접속기와 관리 창을 모두 닫고 위 최신 파일을 내려받아 실행하세요. 문서 폴더에 설치한 뒤 새 바로가기로 열 수 있습니다. 게임·세이브를 다시 설치할 필요는 없습니다.
파일 교체·손상 차단·복원은 격리된 시험 파일로 검사했습니다. 다운로드한 새 접속기의 자동 교체·재시작 전체 과정은 도구 정책 차단으로 아직 검증하지 못했습니다.
0.1.4에서는 로컬 소스의 시험 프로그램으로 실제 프로세스 종료 대기→파일 교체→백업→새 프로세스 실행을 추가 검증했습니다. 회귀 검사 57개와 공개 ZIP/접속기의 다운로드·파일 검사를 통과했습니다.
0.1.5에서는 회귀 검사 60개와 격리된 실제 Windows 폼의 자동 준비·실패·재시도·종료 검사 23개를 통과했습니다. 실제 배너로드 설치 경로의 자동 준비 완료도 확인했습니다. 게임/서버가 켜져 있어도 이미 일치하는 파일은 읽기 검사하며, 실제 파일을 바꿔야 할 때는 안전하게 종료하도록 안내합니다.
보안 한계: 별도 배포 서명과 Windows 게시자 서명은 아직 없습니다. GitHub 계정이나 게시 권한을 탈취당하면 파일 해시만으로 악성 업데이트를 차단할 수 없습니다. 관리자 계정의 2FA/패스키와 게시 권한 보호가 필요합니다. 접속기는 백신이나 서버 인증을 대체하지 않습니다.
접속기 검사는 모드 원본의 동기화 버그를 해결하거나 서버의 접속 권한을 대체하지 않습니다.
